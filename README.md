# Python Medical Data Validator

A Python program that validates medical records and checks whether patient data follows the required format.

## Features

- Validates patient IDs
- Checks patient age
- Validates gender information
- Checks diagnosis data
- Validates medication lists
- Validates visit IDs
- Detects missing or incorrect data
- Displays whether the medical records are valid

## Concepts Used

- Python dictionaries
- Lists and tuples
- Functions
- Loops and conditionals
- Sets
- Regular expressions (`re`)
- Data validation
- `isinstance()`
- `enumerate()`

## How to Run

Run the program with Python:

python medical_data_validator.py

## Example Output

Medical Data Validator
----------------------
Valid format.

## Purpose

This project was built to practice working with Python dictionaries, data structures, regular expressions, and data validation.
